#Abstract

Streaming video diffusion models typically generate each new chunk by conditioning on recent visual history. This local context can support plausible motion, but it does not explicitly preserve a shared world state across agents and long rollouts. We study this problem in two-player Minecraft video generation, where each agent observes only a partial first-person view of the same evolving world.

We propose GenAgent, a streaming multi-agent autoregressive diffusion model with world state registers. The registers form a persistent, update-able world cache: after each generated context frame, the model commits an updated register that summarizes global layout, object configuration, and agent status.

Key Distinction

The cache is a world-state-level representation, not a KV cache or execution-level inference trick. It is a learned belief about the shared scene that conditions future generation.

#Method

We adopt the multi-agent world-model setting of Solaris, where multiple agents act in a single shared world and the model predicts each future video stream from past observations and actions. Our key change is to separate frame generation from state persistence: visual tokens model the next frames, while register tokens carry compact world state across rollout steps.

At rollout step \(i\), the model updates a persistent register from the previous register and recent local context, then uses that committed register to generate the next frame:
\[ \mathbf{r}_i=\pi_\theta(\mathbf{r}_{i-1},\mathbf{x}_{i-W+1},\ldots,\mathbf{x}_i,a_i),\qquad p_\theta(\mathbf{x}_{i+1}\mid \mathbf{x}_{i-W+1},\ldots,\mathbf{x}_i,a_{i+1},\mathbf{r}_i). \]
The register chain is causal at the world-state level: each committed register immediately precedes and conditions the next generated frame.

Grounding the World State

A core question is not only how to store state, but what the state should represent. We ground each committed register with auxiliary targets that make the hidden world state inspectable: per-agent simulator statistics, bird's-eye-view scene layout, and scene text. These heads are used during training and discarded at inference, so the supervision does not increase rollout cost.

Analysis

Registers alone improve over Solaris, suggesting that a dedicated state pathway already helps the model avoid recomputing world information from local context. Explicit world-state targets push performance further by specifying what the registers should preserve. The MoT architecture becomes especially useful when registers carry richer semantic state, separating visual frame computation from state-register computation while retaining shared attention.

Supervision Signals

Registers alone improve world score from 81.0 to 93.8; explicit state targets push the representation toward verifiable world information.
